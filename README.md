# ✊ Rock, 📄 Paper, ✂️ Scissors

A clean, modern **Rock-Paper-Scissors** game built with HTML, CSS, and JavaScript.  
Play against the computer and prove who's the boss! 🔥

---

## 🚀 Features

- User chooses between rock, paper, or scissors
- Computer picks a random choice
- Displays the result of each round (win, lose, draw)
- Keeps track of scores in real time
- Custom modern design with animations and responsive layout

---

## 🛠️ Built With

- **HTML5**  
- **CSS3** (custom gradients, shadows, transitions)
- **Vanilla JavaScript** (no libraries or frameworks)
